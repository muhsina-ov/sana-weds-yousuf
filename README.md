# Ivory Waltz

Layered faceless couple illustration with cream linen atmosphere, mouse + scroll parallax, and a soft paper-curtain open.

**Config:** `src/config.ts`  
**Best for:** Nikah / soft modern Muslim weddings, cream-and-black aesthetic

## Layers

| File | Role |
|------|------|
| `public/assets/layers/layer-01-background.png` | Brushed cream canvas |
| `public/assets/layers/layer-02-shadows.png` | Soft ground shadows |
| `public/assets/layers/layer-03-groom.png` | Depth ghost — groom |
| `public/assets/layers/layer-04-bride.png` | Depth ghost — bride |
| `public/assets/layers/layer-05-bouquet.png` | Floating calla bouquet |
| `public/assets/layers/layer-couple.png` | Hero couple cutout |
